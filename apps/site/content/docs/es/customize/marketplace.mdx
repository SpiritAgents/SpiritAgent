El marketplace instala **extensiones** para Desktop y la CLI. Las extensiones pueden añadir herramientas, fragmentos de indicaciones del sistema, flujos de aprobación o preguntas, configuraciones, almacenamiento de secretos y UI del host.

## Instalación

- **Registro** — navega e instala desde el catálogo predeterminado (`https://raw.githubusercontent.com/SpiritAgents/registry/refs/heads/main/registry/`)
- **ZIP** — importa un archivo (`spirit extension import ./extension.zip` o **Configuración → Extensiones**)

Canales:

| Canal | Significado |
| --- | --- |
| `stable` | Predeterminado |
| `preview` | Pre-lanzamiento |
| `experimental` | Puede cambiar o romperse |

Desktop tiene una vista de marketplace (búsqueda, destacados, readme, registro de cambios, versiones, revisión antes de instalar). La CLI tiene `spirit extension marketplace list|detail|readme|install`, además de `list`, `import` y `remove`.

Para crear una extensión, consulta [Extensiones](../develop/extensions.mdx).
