Spirit guarda los binarios y los datos en lugares diferentes. Mezclarlos es la razón habitual por la que «instalé la CLI pero la configuración está vacía».

## Directorio de datos

Se puede sobrescribir con `SPIRIT_DATA_DIR`. El servidor también puede usar `SPIRIT_SERVER_DATA_DIR` (que tiene prioridad sobre el anterior).

| SO       | Default                                                     |
| -------- | ----------------------------------------------------------- |
| macOS    | `~/Library/Application Support/Spirit`                 |
| Windows  | `%APPDATA%\Spirit`                                     |
| Linux    | `$XDG_DATA_HOME/Spirit` o `~/.local/share/Spirit` |
| Fallback | `~/.spirit-data`                                           |

Archivos típicos:

```
{spiritDataDir}/
  config.json
  mcp.json
  hooks.json
  rule.md
  skills/
  chats/
  plans/
  extensions/
  automations/
  dreams/
  server.token
  server/instances/
```

Los binarios de la CLI viven en `SPIRIT_HOME` (`~/.spirit` o `%LOCALAPPDATA%\Spirit`). Ese no es este directorio. Ver [Instalar CLI](./install/cli.mdx).

## config.json v2

`schemaVersion` debe ser `2`. La versión 1 se rechaza: elimina el archivo antiguo y [vuelve a conectar un proveedor](./providers.mdx).

Campos principales:

- `providerGroups` — casas conectadas, base de API, transporte, modelos
- `activeModel`
- `imageGenerationModel` / `videoGenerationModel` / `lightweightChatModel`

Las claves **no** están en este archivo. Viven en el [keyring](./security.mdx).

## Espacio de trabajo `.spirit/`

| Ruta                 | Rol                                                          |
| -------------------- | ------------------------------------------------------------ |
| `.spirit/rule.md`    | Regla del [espacio de trabajo](./customize/rules.mdx)        |
| `.spirit/skills/`    | Habilidades del [espacio de trabajo](./customize/skills.mdx) |
| `.spirit/mcp.json`   | MCP del [espacio de trabajo](./customize/mcp.mdx)            |
| `.spirit/hooks.json` | Hooks del [espacio de trabajo](./customize/hooks.mdx)        |

También se usan: `{workspace}/AGENTS.md`, `{workspace}/.agents/skills/`, `{workspace}/plans/`.

## Variables de entorno

| Variable                                                          | Rol                                     |
| ----------------------------------------------------------------- | --------------------------------------- |
| `SPIRIT_DATA_DIR`                                           | Directorio de datos                     |
| `SPIRIT_SERVER_DATA_DIR`                                          | Directorio de datos del servidor (gana) |
| `SPIRIT_ACP_DATA_DIR` / `SPIRIT_ACP_WORKSPACE`                    | [ACP](./acp.mdx)                        |
| `SPIRIT_HOME` / `SPIRIT_VERSION` / `SPIRIT_DOWNLOAD_HOST`         | Instalador de CLI                       |
| `SPIRIT_API_KEY` / `SPIRIT_API_BASE`                              | Overrides de proceso [CLI](./cli.mdx)   |
| `SPIRIT_WEB_HOST` / `SPIRIT_WEB_PORT` / `SPIRIT_DESKTOP_WEB_HOST` | Host web de escritorio                  |
| `SPIRIT_TERMINAL_SHELL`                                           | Shell PTY de escritorio                 |
