市集為 Desktop 和 CLI 安裝**擴充功能**。擴充功能可以新增工具、系統提示詞片段、核准或問題流程、設定、密鑰儲存和主機 UI。

## 安裝

- **登錄檔** — 從預設目錄瀏覽並安裝 (`https://raw.githubusercontent.com/SpiritAgents/registry/refs/heads/main/registry/`)
- **ZIP** — 匯入封存檔 (`spirit extension import ./extension.zip` 或 **設定 → 擴充功能**)

頻道：

| 頻道           | 意義           |
| -------------- | -------------- |
| `stable`       | 預設           |
| `preview`      | 預發布         |
| `experimental` | 可能變更或破壞 |

Desktop 具有市集檢視（搜尋、精選、README、變更日誌、版本、安裝前檢閱）。CLI 具有 `spirit extension marketplace list|detail|readme|install`，以及 `list`、`import` 和 `remove`。

若要編寫擴充功能，請參閱 [擴充功能](../develop/extensions.mdx)。
