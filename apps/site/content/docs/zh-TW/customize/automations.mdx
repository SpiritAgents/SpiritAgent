自動化運行 Agent 任務，而無需您坐在 Composer 前。

## 觸發器

- **時間** — 每小時、每日或每週
- **GitHub** — 在您指定的儲存庫（`owner` + `repo`）上觸發 `pull_request_created` 或 `issue_created`

GitHub 觸發器需先連接[整合](./integrations.mdx)。若未連接 GitHub，觸發器選單將不會提供這些事件。

資料存放於 `{spiritDataDir}/automations/`。在 Desktop 上開啟 Automations 檢視以查看歷史記錄和設定。

CLI 無法建立或執行此 UI。請使用 [Desktop](../desktop.mdx)。
