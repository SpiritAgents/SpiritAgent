Spirit 將二進位檔和資料存放在不同的位置。把它們混淆是「我安裝了 CLI 但設定是空的」的常見原因。

## 資料目錄

使用 `SPIRIT_AGENT_DATA_DIR` 覆寫。伺服器也可以使用 `SPIRIT_SERVER_DATA_DIR`（優先於前者）。

| 作業系統 | 預設 |
| --- | --- |
| macOS | `~/Library/Application Support/SpiritAgent` |
| Windows | `%APPDATA%\SpiritAgent` |
| Linux | `$XDG_DATA_HOME/SpiritAgent` 或 `~/.local/share/SpiritAgent` |
| 後備 | `~/.spirit-agent` |

典型檔案：

```
{spiritDataDir}/
  config.json
  mcp.json
  hooks.json
  rule.md
  skills/
  chats/
  plans/
  extensions/
  automations/
  dreams/
  server.token
  server/instances/
```

CLI 二進位檔位於 `SPIRIT_HOME`（`~/.spirit` 或 `%LOCALAPPDATA%\Spirit`）之下。那不是這個目錄。請參閱 [安裝 CLI](./install/cli.mdx)。

## config.json v2

`schemaVersion` 必須是 `2`。版本 1 會被拒絕——刪除舊檔案並[重新連線提供者](./providers.mdx)。

核心欄位：

- `providerGroups` — 已連線的家、API 基礎、傳輸、模型
- `activeModel`
- `imageGenerationModel` / `videoGenerationModel` / `lightweightChatModel`

金鑰**不**在此檔案中。它們位於[金鑰圈](./security.mdx)中。

## 工作區 `.spirit/`

| 路徑 | 角色 |
| --- | --- |
| `.spirit/rule.md` | 工作區[規則](./customize/rules.mdx) |
| `.spirit/skills/` | 工作區[技能](./customize/skills.mdx) |
| `.spirit/mcp.json` | 工作區 [MCP](./customize/mcp.mdx) |
| `.spirit/hooks.json` | 工作區[鉤子](./customize/hooks.mdx) |

也使用：`{workspace}/AGENTS.md`、`{workspace}/.agents/skills/`、`{workspace}/plans/`。

## 環境變數

| 變數 | 角色 |
| --- | --- |
| `SPIRIT_AGENT_DATA_DIR` | 資料目錄 |
| `SPIRIT_SERVER_DATA_DIR` | 伺服器資料目錄（優先） |
| `SPIRIT_ACP_DATA_DIR` / `SPIRIT_ACP_WORKSPACE` | [ACP](./acp.mdx) |
| `SPIRIT_HOME` / `SPIRIT_VERSION` / `SPIRIT_DOWNLOAD_HOST` | CLI 安裝程式 |
| `SPIRIT_API_KEY` / `SPIRIT_API_BASE` | [CLI](./cli.mdx) 程序覆寫 |
| `SPIRIT_WEB_HOST` / `SPIRIT_WEB_PORT` / `SPIRIT_DESKTOP_WEB_HOST` | 桌面網頁主機 |
| `SPIRIT_TERMINAL_SHELL` | 桌面 PTY Shell |
