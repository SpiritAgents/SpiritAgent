---
title: 子代理
description: 將一個有範圍的任務委派給子會話，可選擇在 git worktree 中進行。
---

代理可以呼叫 `subagent` 來啟動子會話。子代理處理隔離的任務，並僅將最終結果回傳給父代理。

## 參數

| 欄位 | 必填 | 角色 |
| --- | --- | --- |
| `task` | 是 | 子代理應該做什麼 |
| `success_criteria` | 否 | 子代理如何知道任務已完成 |
| `context_summary` | 否 | 簡短的背景資訊，子代理不必重新探索 |
| `files_to_inspect` | 否 | 優先閱讀的路徑 |
| `expected_output` | 否 | 父代理期望回傳的結果格式 |
| `worktree` | 否 | `true` 表示在隔離的 git worktree 中編輯 |

當子代理會編輯檔案，且其他子代理可能同時編輯時，請使用 `worktree: true`。若為唯讀工作，則省略該參數。

## 限制

已在 worktree 中執行的子代理無法再啟動另一個 worktree。會話開始和結束時可以執行 hooks（`subagentStart` / `subagentEnd`）。您可以從 Desktop 的子代理檢視器或 CLI TUI 的 `/subagents` 檢視子會話。
