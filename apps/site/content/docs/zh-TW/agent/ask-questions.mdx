---
title: 提出問題
description: 結構化問卷，會暫停 agent 直到您回答。
---

`ask_questions` 是 agent 在繼續之前詢問您做決定的方式。主機會顯示問卷：每個項目可以有預設選項加上自訂文字欄位。

執行會**暫停**。該工具不會在背景執行。您提交答案後，agent 會帶著這些答案在上下文中繼續執行。

## 您會在哪裡看到它

Plan 模式是常見的位置——agent 被指示在草擬計劃前先釐清。Agent 模式仍可在選擇會改變工作時提問。

[略過核准](./approvals.mdx) **不會**跳過 `ask_questions`。

## 無頭 CLI

`spirit -p` 無法顯示問卷。如果模型呼叫 `ask_questions`，程序會失敗。請使用 TUI，或讓提示詞夠具體以至於不需要做決定。
