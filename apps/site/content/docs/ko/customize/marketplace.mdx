마켓플레이스는 Desktop 및 CLI용 **확장 기능**을 설치합니다. 확장 기능은 도구, 시스템 프롬프트 조각, 승인 또는 질문 흐름, 설정, 비밀 저장소 및 호스트 UI를 추가할 수 있습니다.

## 설치

- **레지스트리** — 기본 카탈로그에서 찾아보고 설치합니다 (`https://raw.githubusercontent.com/SpiritAgents/registry/refs/heads/main/registry/`)
- **ZIP** — 아카이브를 가져옵니다 (`spirit extension import ./extension.zip` 또는 **설정 → 확장 기능**)

채널:

| 채널           | 의미                      |
| -------------- | ------------------------- |
| `stable`       | 기본                      |
| `preview`      | 사전 릴리스               |
| `experimental` | 변경되거나 중단될 수 있음 |

Desktop에는 마켓플레이스 보기(검색, 추천, readme, 변경 로그, 버전, 설치 전 검토)가 있습니다. CLI에는 `spirit extension marketplace list|detail|readme|install`와 `list`, `import`, `remove`가 있습니다.

확장 기능을 작성하려면 [확장 기능](../develop/extensions.mdx)을 참조하세요.
