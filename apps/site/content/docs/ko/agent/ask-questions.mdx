---

`ask_questions`는 에이전트가 계속 진행하기 전에 결정을 요청하는 방법입니다. 호스트는 설문지를 표시합니다: 각 항목은 사전 설정 옵션과 사용자 정의 텍스트 필드를 가질 수 있습니다.

실행이 **일시 중지**됩니다. 도구는 백그라운드에서 실행되지 않습니다. 답변을 제출하면 에이전트는 해당 답변을 컨텍스트에 포함하여 재개합니다.

## 이 기능을 볼 수 있는 곳

일반적으로 플랜 모드에서 볼 수 있습니다 — 에이전트는 계획을 세우기 전에 명확히 하도록 지시받습니다. 에이전트 모드에서도 선택이 작업을 변경할 수 있을 때 질문할 수 있습니다.

[승인 건너뛰기](./approvals.mdx)는 `ask_questions`를 **건너뛰지** 않습니다.

## 헤드리스 CLI

`spirit -p`는 설문지를 표시할 수 없습니다. 모델이 `ask_questions`를 호출하면 프로세스가 실패합니다. TUI를 사용하거나 결정이 필요 없도록 프롬프트를 충분히 구체적으로 만드십시오.
