Spirit은 바이너리와 데이터를 서로 다른 위치에 저장합니다. 이 둘을 혼동하는 것이 “CLI를 설치했는데 설정이 비어 있다”는 일반적인 이유입니다.

## 데이터 디렉터리

`SPIRIT_DATA_DIR`로 재정의할 수 있습니다. 서버는 `SPIRIT_SERVER_DATA_DIR`도 사용할 수 있습니다(전자보다 우선).

| OS      | 기본값                                                         |
| ------- | -------------------------------------------------------------- |
| macOS   | `~/Library/Application Support/Spirit`                    |
| Windows | `%APPDATA%\Spirit`                                        |
| Linux   | `$XDG_DATA_HOME/Spirit` 또는 `~/.local/share/Spirit` |
| 폴백    | `~/.spirit-data`                                              |

일반적인 파일:

```
{spiritDataDir}/
  config.json
  mcp.json
  hooks.json
  rule.md
  skills/
  chats/
  plans/
  extensions/
  automations/
  dreams/
  server.token
  server/instances/
```

CLI 바이너리는 `SPIRIT_HOME` (`~/.spirit` 또는 `%LOCALAPPDATA%\Spirit`)에 있습니다. 이는 이 디렉터리가 아닙니다. [CLI 설치](./install/cli.mdx)를 참조하세요.

## config.json v2

`schemaVersion`은 `2`여야 합니다. 버전 1은 거부됩니다 — 이전 파일을 삭제하고 [프로바이더를 다시 연결](./providers.mdx)하세요.

핵심 필드:

- `providerGroups` — 연결된 하우스, API 베이스, 전송, 모델
- `activeModel`
- `imageGenerationModel` / `videoGenerationModel` / `lightweightChatModel`

키(Key)는 이 파일에 **없습니다**. 키는 [키링](./security.mdx)에 있습니다.

## 작업공간 `.spirit/`

| 경로                 | 역할                                    |
| -------------------- | --------------------------------------- |
| `.spirit/rule.md`    | 작업공간 [규칙](./customize/rules.mdx)  |
| `.spirit/skills/`    | 작업공간 [스킬](./customize/skills.mdx) |
| `.spirit/mcp.json`   | 작업공간 [MCP](./customize/mcp.mdx)     |
| `.spirit/hooks.json` | 작업공간 [훅](./customize/hooks.mdx)    |

또한 사용됨: `{workspace}/AGENTS.md`, `{workspace}/.agents/skills/`, `{workspace}/plans/`.

## 환경 변수

| 변수                                                              | 역할                             |
| ----------------------------------------------------------------- | -------------------------------- |
| `SPIRIT_DATA_DIR`                                           | 데이터 디렉터리                  |
| `SPIRIT_SERVER_DATA_DIR`                                          | 서버 데이터 디렉터리(우선)       |
| `SPIRIT_ACP_DATA_DIR` / `SPIRIT_ACP_WORKSPACE`                    | [ACP](./acp.mdx)                 |
| `SPIRIT_HOME` / `SPIRIT_VERSION` / `SPIRIT_DOWNLOAD_HOST`         | CLI 설치 프로그램                |
| `SPIRIT_API_KEY` / `SPIRIT_API_BASE`                              | [CLI](./cli.mdx) 프로세스 재정의 |
| `SPIRIT_WEB_HOST` / `SPIRIT_WEB_PORT` / `SPIRIT_DESKTOP_WEB_HOST` | 데스크톱 웹 호스트               |
| `SPIRIT_TERMINAL_SHELL`                                           | 데스크톱 PTY 셸                  |
