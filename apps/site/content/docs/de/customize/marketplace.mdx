Der Marketplace installiert **Erweiterungen** für Desktop und CLI. Erweiterungen können Werkzeuge, System-Prompt-Fragmente, Genehmigungs- oder Fragenabläufe, Einstellungen, geheime Speicherung und Host-Benutzeroberfläche hinzufügen.

## Installieren

- **Registry** – Durchsuchen und Installieren aus dem Standardkatalog (`https://raw.githubusercontent.com/SpiritAgents/registry/refs/heads/main/registry/`)
- **ZIP** – Importieren Sie ein Archiv (`spirit extension import ./extension.zip` oder **Einstellungen → Erweiterungen**)

Kanäle:

| Kanal          | Bedeutung                     |
| -------------- | ----------------------------- |
| `stable`       | Standard                      |
| `preview`      | Vorabversion                  |
| `experimental` | Kann sich ändern oder brechen |

Desktop verfügt über eine Marketplace-Ansicht (Suche, empfohlen, Readme, Änderungsprotokoll, Versionen, Überprüfung vor der Installation). Das CLI verfügt über `spirit extension marketplace list|detail|readme|install` sowie `list`, `import` und `remove`.

Zum Erstellen einer Erweiterung siehe [Erweiterungen](../develop/extensions.mdx).
