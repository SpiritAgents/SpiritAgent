市场为 Desktop 和 CLI 安装**扩展**。扩展可以加工具、system 片段、审批或问卷流程、设置、密钥存储和宿主 UI。

## 安装

- **Registry** — 从默认目录浏览安装（`https://raw.githubusercontent.com/SpiritAgents/registry/refs/heads/main/registry/`）
- **ZIP** — 导入压缩包（`spirit extension import ./extension.zip` 或 **设置 → 扩展**）

通道：

| 通道 | 含义 |
| --- | --- |
| `stable` | 默认 |
| `preview` | 预发布 |
| `experimental` | 可能变或坏 |

Desktop 有市场视图（搜索、精选、readme、changelog、版本、安装前确认）。CLI 有 `spirit extension marketplace list|detail|readme|install`，以及 `list`、`import`、`remove`。

编写扩展见[扩展](../develop/extensions.mdx)。
