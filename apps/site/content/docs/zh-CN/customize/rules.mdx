Rules 是 Agent 会一直考虑的 Markdown。一共三个槽位：

| 范围 | 路径 |
| --- | --- |
| 工作区 agents 文件 | `{workspace}/AGENTS.md` |
| 工作区 Spirit rule | `{workspace}/.spirit/rule.md` |
| 用户 rule | `{spiritDataDir}/rule.md` |

项目约定写进 `AGENTS.md`，谁打开仓库都能看到。Spirit 专用、又不想放进通用 agents 文件的内容写 `.spirit/rule.md`。跟着你跨工作区走的偏好写用户 rule。

在 **设置 → 规则** 管理槽位。内置 Skill `create-rule` 可以帮你起草。

Rules 保持短。Agent 已经有工具；在 rule 里再列一遍工具清单只会摊薄注意力。
