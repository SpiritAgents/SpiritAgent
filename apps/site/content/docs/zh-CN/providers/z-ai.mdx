---
title: 连接 Z.ai
description: 连接 Z.ai，可选 GLM Coding Plan 端点。
---

在 Z.ai 控制台创建 API Key。套餐说明见 [GLM Coding Plan](https://docs.z.ai/devpack/quick-start)。

## 连接

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. 打开 **设置 → 模型**。
2. 选这家提供商，走完连接向导。
3. Spirit 把 Key 写入系统钥匙串（`SpiritAgent`），再导入模型。

  </Tab>
  <Tab value="CLI">

在 TUI 里运行 `/model add`，或在 shell 里：

```bash
spirit model add
```

  </Tab>
</Tabs>

## 传输

固定 **Chat Completions API**。默认 Base：`https://api.z.ai/api/paas/v4`。

## 套餐端点

在向导里打开 **GLM Coding Plan**，改用 `https://api.z.ai/api/coding/paas/v4`，不再走默认 PaaS Base。

## 能力

导入后即可对话。推理跟模型走。
