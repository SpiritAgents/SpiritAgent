---
title: 连接 BytePlus
description: 连接 BytePlus Ark，并在 Chat Completions 与 Responses 之间选择。
---

在 BytePlus 控制台创建 API Key。

## 连接

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. 打开 **设置 → 模型**。
2. 选这家提供商，走完连接向导。
3. Spirit 把 Key 写入系统钥匙串（`SpiritAgent`），再导入模型。

  </Tab>
  <Tab value="CLI">

在 TUI 里运行 `/model add`，或在 shell 里：

```bash
spirit model add
```

  </Tab>
</Tabs>

## 传输

可选手： **Chat Completions** 或 **Responses API**。默认 Base：`https://ark.ap-southeast.bytepluses.com/api/v3`。

## 能力

导入后即可对话。其他能力跟目录走。
