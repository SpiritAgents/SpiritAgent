---
title: 连接 Kimi Code
description: 连接 Kimi Code 编程端点，与 Moonshot AI 分开。
---

在 [Kimi Code 控制台](https://www.kimi.com/code/console) 创建 API Key。

## 连接

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. 打开 **设置 → 模型**。
2. 选这家提供商，走完连接向导。
3. Spirit 把 Key 写入系统钥匙串（`SpiritAgent`），再导入模型。

  </Tab>
  <Tab value="CLI">

在 TUI 里运行 `/model add`，或在 shell 里：

```bash
spirit model add
```

  </Tab>
</Tabs>

## 传输

固定 **Chat Completions API**。默认 Base：`https://api.kimi.com/coding/v1`。Messages Base 为 `https://api.kimi.com/coding`，但向导不提供选择器。

## 能力

导入后即可对话。托管搜索（若有）只属于这家，不属于 moonshot-ai。
