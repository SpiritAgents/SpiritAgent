---
title: 连接阶跃星辰
description: 连接阶跃星辰，可选 Step Plan 端点。
---

在[阶跃星辰平台](https://platform.stepfun.com) 创建 API Key。套餐说明见 [Step Plan](https://platform.stepfun.com/docs/zh/step-plan/integrations/reasoning-api)。

## 连接

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. 打开 **设置 → 模型**。
2. 选这家提供商，走完连接向导。
3. Spirit 把 Key 写入系统钥匙串（`SpiritAgent`），再导入模型。

  </Tab>
  <Tab value="CLI">

在 TUI 里运行 `/model add`，或在 shell 里：

```bash
spirit model add
```

  </Tab>
</Tabs>

## 传输

固定 **Chat Completions API**。默认 Base：`https://api.stepfun.com/v1`。

## 套餐端点

**Step Plan** 会改到 `https://api.stepfun.com/step_plan/v1`。

## 能力

导入后即可对话。推理跟模型走。
