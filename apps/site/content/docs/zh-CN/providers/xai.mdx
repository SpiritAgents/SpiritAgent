---
title: 连接 SpaceXAI
description: 用 Chat Completions Key 连接 SpaceXAI（提供商 id 为 `xai`）。
---

在 SpaceXAI 控制台创建 API Key。

## 连接

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. 打开 **设置 → 模型**。
2. 选这家提供商，走完连接向导。
3. Spirit 把 Key 写入系统钥匙串（`SpiritAgent`），再导入模型。

  </Tab>
  <Tab value="CLI">

在 TUI 里运行 `/model add`，或在 shell 里：

```bash
spirit model add
```

  </Tab>
</Tabs>

## 传输

固定 **Chat Completions API**（`openai-compatible`）。默认 Base：`https://api.x.ai/v1`。

## 能力

导入后即可对话。推理、生图、生视频跟导入目录走，出现对应能力时再指定槽位。
