---
title: 连接 SiliconFlow
description: 连接 SiliconFlow，选择站点，并在 Chat Completions 与 Messages 之间选择。
---

在对应站点的控制台创建 API Key：[国际站](https://cloud.siliconflow.com/me/account/ak) 或 [中国站](https://cloud.siliconflow.cn/me/account/ak)。

## 连接

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. 打开 **设置 → 模型**。
2. 选这家提供商，走完连接向导。
3. Spirit 把 Key 写入系统钥匙串（`SpiritAgent`），再导入模型。

  </Tab>
  <Tab value="CLI">

在 TUI 里运行 `/model add`，或在 shell 里：

```bash
spirit model add
```

  </Tab>
</Tabs>

## 传输

可选手： **Chat Completions** 或 **Messages**。

## 站点

- **国际**（默认）— `https://api.siliconflow.com/v1`
- **中国** — `https://api.siliconflow.cn/v1`

## 能力

导入后即可对话。其他能力跟目录走。
