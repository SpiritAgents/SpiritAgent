---
title: 连接 Cloudflare AI Gateway
description: 用 Cloudflare 账户 ID、可选 gateway ID 和 API token 连接。
---

在 [Cloudflare 控制台](https://developers.cloudflare.com/ai-gateway/) 创建 API token，并准备好账户 ID。

## 连接

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. 打开 **设置 → 模型**。
2. 选这家提供商，走完连接向导。
3. Spirit 把 Key 写入系统钥匙串（`SpiritAgent`），再导入模型。

  </Tab>
  <Tab value="CLI">

在 TUI 里运行 `/model add`，或在 shell 里：

```bash
spirit model add
```

  </Tab>
</Tabs>

## 传输

可选手： **Chat Completions**、**Open Responses** 或 **Messages**。Base 由账户拼出：`https://api.cloudflare.com/client/v4/accounts/{accountId}/ai/v1`。

## 云字段

- **账户 ID**（必填）— 32 位十六进制
- **Gateway ID**（可选）

没有账户 ID，向导无法拼出 API Base。

## 能力

对话和其他能力跟网关暴露的模型走。
