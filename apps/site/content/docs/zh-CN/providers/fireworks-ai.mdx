---
title: 连接 Fireworks AI
description: 连接 Fireworks Inference，可选择传输。
---

在 [Fireworks 控制台](https://app.fireworks.ai/settings/users/api-keys) 创建 API Key。

## 连接

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. 打开 **设置 → 模型**。
2. 选这家提供商，走完连接向导。
3. Spirit 把 Key 写入系统钥匙串（`SpiritAgent`），再导入模型。

  </Tab>
  <Tab value="CLI">

在 TUI 里运行 `/model add`，或在 shell 里：

```bash
spirit model add
```

  </Tab>
</Tabs>

## 传输

可选手： **Chat Completions**、**Messages** 或 **Open Responses**。Chat / Responses Base：`https://api.fireworks.ai/inference/v1`。Messages Base：`https://api.fireworks.ai/inference`。

## 能力

导入后即可对话。其他能力跟 Fireworks 目录走。
