---
title: 连接 OpenRouter
description: 一把 OpenRouter Key 可到达多家上游。向导里选择传输。
---

在 [OpenRouter](https://openrouter.ai/keys) 创建 Key。

## 连接

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. 打开 **设置 → 模型**。
2. 选这家提供商，走完连接向导。
3. Spirit 把 Key 写入系统钥匙串（`SpiritAgent`），再导入模型。

  </Tab>
  <Tab value="CLI">

在 TUI 里运行 `/model add`，或在 shell 里：

```bash
spirit model add
```

  </Tab>
</Tabs>

## 传输

可选手： **Chat Completions**、**Open Responses** 或 **Messages**。默认 Base：`https://openrouter.ai/api/v1`。

## 能力

对话，以及 OpenRouter 目录标了生图 / 生视频时的对应槽位。
