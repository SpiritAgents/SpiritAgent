---
title: 连接 Vercel AI Gateway
description: 用一把 Key，经 Vercel AI Gateway 路由多家上游模型。
---

在 [Vercel AI Gateway](https://vercel.com/docs/ai-gateway) 控制台创建 Key。

## 连接

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. 打开 **设置 → 模型**。
2. 选这家提供商，走完连接向导。
3. Spirit 把 Key 写入系统钥匙串（`SpiritAgent`），再导入模型。

  </Tab>
  <Tab value="CLI">

在 TUI 里运行 `/model add`，或在 shell 里：

```bash
spirit model add
```

  </Tab>
</Tabs>

## 传输

固定 **Open Responses API**（`open-responses`）。默认 Base：`https://ai-gateway.vercel.sh/v1`。

## 能力

对话以及网关目录里标出的能力。生图以目录的 `type=image` 为准，不用 tags 推断。

## 已知坑

不要用 tags 推断视觉或生图。经此网关的 MiniMax M3 在 Open Responses 下不会返回可展示的思考流。
