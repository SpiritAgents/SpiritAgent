---
title: 连接 Google Vertex AI
description: 用 GCP 项目、位置和一种认证方式连接 Vertex AI。
---

使用已开通 Vertex AI 的 GCP 项目。认证是 ADC、服务账号或 Express API Key，不是普通 OpenAI Key。

## 连接

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. 打开 **设置 → 模型**。
2. 选这家提供商，走完连接向导。
3. Spirit 把 Key 写入系统钥匙串（`SpiritAgent`），再导入模型。

  </Tab>
  <Tab value="CLI">

在 TUI 里运行 `/model add`，或在 shell 里：

```bash
spirit model add
```

  </Tab>
</Tabs>

## 传输

固定 **Chat Completions API**。若配置要了 Responses 或 Messages，会回落到 Chat Completions。Base 为 `https://{location}-aiplatform.googleapis.com/v1/projects/{project}/locations/{location}`。

## 云字段

- **GCP 项目 ID** 和 **位置**（必填），例如 `us-central1`
- **认证**
  - **ADC** — 本机 Application Default Credentials（`GOOGLE_APPLICATION_CREDENTIALS`）
  - **服务账号** — client email + 私钥；用来拉模型列表
  - **Express API Key** — 不能自动拉目录，需手填模型 id

## 能力

选定模型后即可对话。没有 GCP 项目、只用 AI Studio Key 时，走 [Google](./google.mdx)。

## 已知坑

Express 模式不能导入模型列表。服务账号模式要同时有 email 和私钥才能列模型。
