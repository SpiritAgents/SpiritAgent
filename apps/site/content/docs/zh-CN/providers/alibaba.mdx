---
title: 连接阿里
description: 连接阿里云模型服务，填写区域、可选 workspaceId，或 Token Plan。
---

在[阿里云百炼 / 模型服务](https://bailian.console.aliyun.com) 创建 API Key。

## 连接

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. 打开 **设置 → 模型**。
2. 选这家提供商，走完连接向导。
3. Spirit 把 Key 写入系统钥匙串（`SpiritAgent`），再导入模型。

  </Tab>
  <Tab value="CLI">

在 TUI 里运行 `/model add`，或在 shell 里：

```bash
spirit model add
```

  </Tab>
</Tabs>

## 传输

固定 **Chat Completions API**。兼容默认：`https://dashscope.aliyuncs.com/compatible-mode/v1`。

## 站点与 workspace

- **cn-beijing**（默认）— `https://{workspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`（需要 workspace id）
- **ap-southeast-1** — 需要 workspace id
- **us-virginia** — `https://dashscope-us.aliyuncs.com/compatible-mode/v1`（不需要 workspace id）
- **eu-central-1** — 需要 workspace id

## 套餐端点

**Token Plan** 会改到 `https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`，并忽略站点 / workspace。说明见 [Token Plan](https://bailian.console.aliyun.com/cn-beijing?tab=doc#/doc/?type=model&url=3029020)。

## 能力

导入后即可对话。其他能力跟目录走。

## 已知坑

即使选了其他站点，Token Plan 也固定走 cn-beijing 套餐端点。
