---
title: 连接 MiniMax
description: 用 Messages API 连接 MiniMax，并选择中国或国际站点。
---

在你要使用的站点对应的 MiniMax 控制台创建 API Key。

## 连接

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. 打开 **设置 → 模型**。
2. 选这家提供商，走完连接向导。
3. Spirit 把 Key 写入系统钥匙串（`SpiritAgent`），再导入模型。

  </Tab>
  <Tab value="CLI">

在 TUI 里运行 `/model add`，或在 shell 里：

```bash
spirit model add
```

  </Tab>
</Tabs>

## 传输

固定 **Messages API**（`anthropic`）。国际 Messages Base：`https://api.minimax.io/anthropic/v1`。

## 站点

- **国际**（默认）— `https://api.minimax.io/v1`（Chat 形态）/ `https://api.minimax.io/anthropic/v1`（Messages）
- **中国** — `https://api.minimaxi.com/v1`

## 能力

导入后即可对话。上游 `/models` 没有多模态字段；只有 M3 被当作支持图 / 视频输入。

## 已知坑

经 Vercel AI Gateway 的 Open Responses，MiniMax M3 不会返回可展示的思考流。
