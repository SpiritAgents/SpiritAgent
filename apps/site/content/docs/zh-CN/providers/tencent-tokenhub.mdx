---
title: 连接腾讯 TokenHub
description: 连接 TokenHub，选择广州或新加坡。传输仅 Chat Completions。
---

在 [腾讯 TokenHub 控制台](https://console.cloud.tencent.com/tokenhub) 创建 API Key。

## 连接

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. 打开 **设置 → 模型**。
2. 选这家提供商，走完连接向导。
3. Spirit 把 Key 写入系统钥匙串（`SpiritAgent`），再导入模型。

  </Tab>
  <Tab value="CLI">

在 TUI 里运行 `/model add`，或在 shell 里：

```bash
spirit model add
```

  </Tab>
</Tabs>

## 传输

固定 **Chat Completions API**。向导不提供 Responses 或 Messages。

## 站点

- **广州**（默认）— `https://tokenhub.tencentmaas.com/v1`
- **新加坡** — `https://tokenhub-intl.tencentmaas.com/v1`

## 能力

导入后即可对话。不要依赖 Chat 注入的联网搜索。

## 已知坑

TokenHub 文档写了 Chat `web_search_options` 和 Responses `web_search`，但实测 Chat 注入无效，Responses 也只覆盖少数模型。因此 Spirit 只保留 Chat Completions。
