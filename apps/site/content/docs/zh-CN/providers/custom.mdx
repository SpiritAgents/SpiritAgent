---
title: 连接自定义 OpenAI 兼容端点
description: 把 Spirit 指到任意 OpenAI 兼容、Open Responses 或 Messages 的 Base URL。
---

使用该端点要求的 API Key。Spirit 不托管自定义提供商。

## 连接

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. 打开 **设置 → 模型**。
2. 选这家提供商，走完连接向导。
3. Spirit 把 Key 写入系统钥匙串（`SpiritAgent`），再导入模型。

  </Tab>
  <Tab value="CLI">

在 TUI 里运行 `/model add`，或在 shell 里：

```bash
spirit model add
```

  </Tab>
</Tabs>

## 传输

可选手： **Chat Completions**、**Open Responses** 或 **Messages**。必须填写 **Base URL**。留空时占位默认是 `https://api.openai.com/v1`。

## Base URL

填写厂商文档里的根地址，若对方要求版本后缀（`/v1`、`/v1/openai` 等）一并带上。自定义端点 Spirit 不会猜路径。

还可以给提供商分组起显示名，方便区分多条自定义端点。

## 能力

连接后导入或手填模型 id。若端点没有 Spirit 能读的目录，在向导里自行标记对话 / 生图 / 生视频能力。
