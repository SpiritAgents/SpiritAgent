---
title: 连接智谱 AI
description: 连接智谱 AI（BigModel），可选 GLM Coding Plan 端点。
---

在 [智谱 AI 控制台](https://bigmodel.cn/console) 创建 API Key。套餐说明见 [GLM Coding Plan](https://docs.bigmodel.cn/cn/coding-plan/quick-start)。

## 连接

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. 打开 **设置 → 模型**。
2. 选这家提供商，走完连接向导。
3. Spirit 把 Key 写入系统钥匙串（`SpiritAgent`），再导入模型。

  </Tab>
  <Tab value="CLI">

在 TUI 里运行 `/model add`，或在 shell 里：

```bash
spirit model add
```

  </Tab>
</Tabs>

## 传输

固定 **Chat Completions API**。默认 Base：`https://open.bigmodel.cn/api/paas/v4`。

## 套餐端点

打开 **GLM Coding Plan** 后改用 `https://open.bigmodel.cn/api/coding/paas/v4`。

## 能力

导入后即可对话。推理跟模型走。
