这些工具作用在工作区根上。Ask 模式可以读和搜，不能创建、编辑、删除或打补丁。

| 工具 | 作用 |
| --- | --- |
| `read_file` | 读文件，或读 `spirit://generated/image|video/<name>` 上的生成资源 |
| `create_file` | 创建文件 |
| `edit_file` | 编辑已有文件 |
| `delete_file` | 删除文件 |
| `glob` | 按 glob 找路径（尊重 `.gitignore`） |
| `grep` | 搜文件内容（尊重 `.gitignore`） |
| `ls` | 列出一个目录，不递归。路径必须是绝对路径 |
| `apply_patch` | 在模型与传输符合条件时打补丁，并替代该路径上的旧文件工具 |

默认审批下，编辑和删除会等你[批准](../agent/approvals.mdx)。

## web_fetch

`web_fetch` 抓取 `http` 或 `https` URL，返回 Markdown。这是宿主工具，不是提供商内置搜索。工作区里没有、又需要看某个页面时用它。
