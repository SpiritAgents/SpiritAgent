---
title: 生图与生视频
description: generate_image 和 generate_video 使用生图、生视频模型槽位。
---

在 **设置 → 模型** 指定了默认生图 / 生视频模型后，Spirit 可以生成一张图或一小段视频。

| 工具 | 参数 |
| --- | --- |
| `generate_image` | `prompt`（必填），可选 `size`（`宽x高`） |
| `generate_video` | `prompt`（必填），可选 `duration`（4–15 秒）、`aspect_ratio`、`resolution` |

Ask 模式不能调用这些工具。槽位设好后，输入框也可以走生图 / 生视频快捷路径。

结果存成生成资源。Agent 之后可用 `read_file` 读 `spirit://generated/image/…` 或 `spirit://generated/video/…`。

如果没有这些工具，说明当前提供商目录没标生图 / 生视频，或槽位是空的。接一家带这些能力的提供商，再指定槽位。见[提供商](../providers.mdx)。
