---
title: 浏览器
description: 仅 Electron 的工作区浏览器和元素选取，不是 Agent 浏览器自动化工具。
---

Desktop（Electron）有 **Browser** 工作区标签。它嵌入一个浏览器，方便你打开本地开发服务器，并把 DOM 元素选进输入框当上下文。

这**不是**名为 `browser_navigate` 的 Agent 工具。Agent 不能自己开车页。你浏览、你选元素；Agent 把附件当指针来读。

Web 客户端和 CLI 没有嵌入的 Browser 标签。

桌面 Computer Use 不是 Spirit 的产品能力。
