title: 提问
description: 结构化问卷会挂起 Agent，直到你答完。
---

`ask_questions` 是 Agent 在继续之前让你做决定的方式。宿主会弹出问卷：每题可以有预设选项，外加自定义文本。

这一轮会**挂起**。工具不会在后台执行。你提交答案后，Agent 带着这些答案继续。

## 什么时候会看到

Plan 模式最常见——系统要求先澄清再写计划。Agent 模式在一个选择会改变做法时也可以问。

[绕过审批](./approvals.mdx) **不会**跳过 `ask_questions`。

## 非交互 CLI

`spirit -p` 弹不出问卷。模型若调用 `ask_questions`，进程会失败。改用 TUI，或把提示写清楚到不需要再做决定。
