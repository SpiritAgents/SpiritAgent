ACP（Agent Client Protocol）已实现为 `spirit-agent-acp`（`@spiritagent/acp-server`）。它走 stdio ndJSON，与 Desktop、CLI 共用数据目录和钥匙串，并可用 `--setup` 连接提供商。

**公开下载页还没有列出 ACP。** 那里的第三列是上架占位，不是安装通道。不要从[上手](./quickstart.mdx)指望能下到 ACP 安装包。

## 如果你已经有构建

```bash
npx @spiritagent/acp-server --setup
```

或把 ACP 客户端（例如 Zed）指到 stdio 入口：

```json
"agent_servers": {
  "Spirit Agent": {
    "command": "node",
    "args": ["path/to/packages/acp-server/dist/src/stdio-entry.js"]
  }
}
```

认证选 **Run in terminal**，做完 `--setup`，再 `authenticate` 和 `session/new`。

| 变量 | 作用 |
| --- | --- |
| `SPIRIT_ACP_WORKSPACE` | 工作区根（默认客户端 cwd） |
| `SPIRIT_ACP_DATA_DIR` | 数据目录；否则走 `SPIRIT_AGENT_DATA_DIR`，再走平台默认 |

ACP 权限用 `request_permission`（允许一次 / 始终允许 / 拒绝）。这是 Spirit [审批](./agent/approvals.mdx) 在 ACP 上的映射，不是下载页上的第四个产品宿主。
