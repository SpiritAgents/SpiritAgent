title: Задать вопросы
description: Структурированные опросники, которые приостанавливают агента, пока вы не ответите.
---

`ask_questions` — это способ, которым агент просит вас принять решение перед продолжением. Хост показывает опросник: каждый пункт может иметь предустановленные варианты плюс поле для произвольного текста.

Запуск **приостанавливается**. Инструмент не выполняется в фоновом режиме. После отправки ответов агент возобновляет работу с этими ответами в контексте.

## Где вы это увидите

Обычно это режим планирования — агенту поручено уточнять перед составлением плана. Режим агента также может задавать вопросы, когда выбор может изменить работу.

[Обход одобрения](./approvals.mdx) **не** пропускает `ask_questions`.

## Headless CLI

`spirit -p` не может показать опросник. Если модель вызывает `ask_questions`, процесс завершается ошибкой. Используйте TUI или сделайте промпт достаточно конкретным, чтобы не требовалось принятия решений.
