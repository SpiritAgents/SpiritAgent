title: Установка CLI
description: Установите CLI Spirit Agent с помощью скрипта установки, SPIRIT_HOME и SPIRIT_VERSION.
---

CLI — это терминальный хост с TUI и неинтерактивным режимом `-p`. Он общается с тем же локальным демоном, что и [Desktop](./desktop.mdx).

## Скрипт установки

macOS и Linux:

```bash
curl -fsSL https://spirit.fast/install | bash
```

Windows (PowerShell):

```powershell
irm https://spirit.fast/install.ps1 | iex
```

Скрипт загружает сборку с `download.spirit.fast`, распаковывает её и добавляет `spirit` в ваш `PATH`.

Откройте новый терминал, затем:

```bash
spirit --version
```

## Куда это устанавливается

Корень установки **не** является каталогом данных Spirit Agent.

|                                                     | По умолчанию                                                                                                                | Переопределение         |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ----------------------- |
| Бинарные файлы CLI                                  | Unix: `~/.spirit` · Windows: `%LOCALAPPDATA%\Spirit`                                                                        | `SPIRIT_HOME`           |
| Сессии, конфигурация, указатели на хранилище ключей | macOS: `~/Library/Application Support/SpiritAgent` · Windows: `%APPDATA%\SpiritAgent` · Linux: `~/.local/share/SpiritAgent` | `SPIRIT_AGENT_DATA_DIR` |

В Unix скрипт создаёт ссылку `$SPIRIT_HOME/bin/spirit` → `$SPIRIT_HOME/cli/current/bin/spirit` и добавляет `export PATH="$SPIRIT_HOME/bin:$PATH"` в `~/.profile`, `~/.bashrc` и `~/.zshrc` (маркер `# spirit-agent cli`).

## Зафиксировать версию или зеркало

| Переменная             | По умолчанию                            | Роль                                     |
| ---------------------- | --------------------------------------- | ---------------------------------------- |
| `SPIRIT_HOME`          | `~/.spirit` или `%LOCALAPPDATA%\Spirit` | Корень установки для бинарных файлов CLI |
| `SPIRIT_VERSION`       | `latest`                                | Сегмент версии в URL загрузки            |
| `SPIRIT_DOWNLOAD_HOST` | `download.spirit.fast`                  | Хост CDN                                 |

```bash
SPIRIT_VERSION=0.1.0 curl -fsSL https://spirit.fast/install | bash
```

Вы также можете загрузить архив CLI со [страницы загрузки](/en-US/download) или [GitHub Releases](https://github.com/SpiritAgents/SpiritAgent/releases/latest) и распаковать его самостоятельно.

## Первый запуск

```bash
cd /path/to/your/project
spirit
```

Это открывает TUI. Добавьте провайдера с помощью `/model add` или из оболочки с помощью `spirit model add`. См. [краткое руководство](../quickstart.mdx).
