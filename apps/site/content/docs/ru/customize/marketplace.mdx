Маркетплейс устанавливает **расширения** для Desktop и CLI. Расширения могут добавлять инструменты, фрагменты системного промпта, потоки одобрения или вопросов, настройки, хранилище секретов и пользовательский интерфейс хоста.

## Установка

- **Реестр** — просматривайте и устанавливайте из каталога по умолчанию (`https://raw.githubusercontent.com/SpiritAgents/registry/refs/heads/main/registry/`)
- **ZIP** — импортируйте архив (`spirit extension import ./extension.zip` или **Настройки → Расширения**)

Каналы:

| Канал | Значение |
| --- | --- |
| `stable` | По умолчанию |
| `preview` | Предварительный выпуск |
| `experimental` | Может измениться или сломаться |

В Desktop есть представление маркетплейса (поиск, рекомендуемое, readme, журнал изменений, версии, просмотр перед установкой). В CLI есть `spirit extension marketplace list|detail|readme|install`, а также `list`, `import` и `remove`.

Чтобы создать расширение, см. [Расширения](../develop/extensions.mdx).
