<Callout type="info">
Только для Desktop.
</Callout>

Автоматизации запускают задание агента без вашего присутствия в Composer.

## Триггеры

- **Время** — ежечасно, ежедневно или еженедельно
- **GitHub** — `pull_request_created` или `issue_created` в репозитории, который вы укажете (`owner` + `repo`)

Для триггеров GitHub сначала необходимо подключить [Интеграции](./integrations.mdx). Если GitHub не подключен, меню триггеров не предложит эти события.

Данные хранятся в `{spiritDataDir}/automations/`. Откройте представление Автоматизации на Desktop, чтобы увидеть историю и настройки.

CLI не может создавать или запускать этот интерфейс. Используйте [Desktop](../desktop.mdx).
