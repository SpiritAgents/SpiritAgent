title: マーケットプレイス

---

マーケットプレイスは、DesktopおよびCLI用の**拡張機能**をインストールします。拡張機能は、ツール、システムプロンプトの断片、承認または質問フロー、設定、シークレットストレージ、ホストUIを追加できます。

## インストール

- **レジストリ** — デフォルトのカタログ（`https://raw.githubusercontent.com/SpiritAgents/registry/refs/heads/main/registry/`）から参照してインストールします。
- **ZIP** — アーカイブをインポートします（`spirit extension import ./extension.zip` または **設定 → 拡張機能**）。

チャンネル：

| チャンネル | 意味 |
| --- | --- |
| `stable` | デフォルト |
| `preview` | プレリリース |
| `experimental` | 変更または破損の可能性あり |

Desktopにはマーケットプレイスビュー（検索、注目、README、変更ログ、バージョン、インストール前のレビュー）があります。CLIには `spirit extension marketplace list|detail|readme|install` に加えて、`list`、`import`、`remove` があります。

拡張機能を作成するには、[拡張機能](../develop/extensions.mdx) を参照してください。
