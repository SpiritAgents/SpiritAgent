O marketplace instala **extensões** para Desktop e CLI. As extensões podem adicionar ferramentas, fragmentos de prompt do sistema, fluxos de aprovação ou perguntas, configurações, armazenamento secreto e interface do host.

## Instalação

- **Registro** — navegue e instale a partir do catálogo padrão (`https://raw.githubusercontent.com/SpiritAgents/registry/refs/heads/main/registry/`)
- **ZIP** — importe um arquivo (`spirit extension import ./extension.zip` ou **Configurações → Extensões**) — (path: li.1)

Canais:

| Canal          | Significado           |
| -------------- | --------------------- |
| `stable`       | Padrão                |
| `preview`      | Pré-lançamento        |
| `experimental` | Pode mudar ou quebrar |

Desktop tem uma visualização de marketplace (pesquisa, em destaque, readme, changelog, versões, revisão antes da instalação). O CLI tem `spirit extension marketplace list|detail|readme|install`, além de `list`, `import` e `remove`.

Para criar uma extensão, veja [Extensões](../develop/extensions.mdx).
