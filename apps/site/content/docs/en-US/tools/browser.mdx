---
title: Browser
description: Electron-only workspace browser and element picker — not an agent browser-automation tool.
---

Desktop (Electron) has a **Browser** workspace tab. It embeds a browser so you can open a local dev server and pick DOM elements into the composer as context.

This is **not** an agent tool named `browser_navigate`. The agent cannot drive pages on its own. You browse; you attach an element; the agent reads that attachment like any other pointer.

The web client and the CLI have no embedded Browser tab.

Computer-use style desktop control is not a Spirit product capability.
