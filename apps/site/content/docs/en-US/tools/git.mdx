---
title: Git
description: Sidebar chips for commit, push, and merge — not a bundled Skill.
---

Git in Spirit is a **workspace panel and composer chips**, not a Skill package. The **Git** tab shows changes and history. Chips on the composer can start **commit**, **push**, or **merge**.

Those chips inject a fixed prompt (including commit-message style inferred from `AGENTS.md` and similar files). The agent then uses workspace and shell tools under your [approval](../agent/approvals.mdx) level.

Do not look for a bundled `git` Skill. Extra git workflow belongs in your own Skill later — the chips stay part of the host UI.
