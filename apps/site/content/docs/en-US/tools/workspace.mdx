---
title: Workspace
description: Read, create, edit, and search files in the workspace you opened.
---

These tools operate on the workspace root. Ask mode can read and search; it cannot create, edit, delete, or apply patches.

| Tool | Role |
| --- | --- |
| `read_file` | Read a file, or a generated asset at `spirit://generated/image/…` or `spirit://generated/video/…` |
| `create_file` | Create a file |
| `edit_file` | Edit an existing file |
| `delete_file` | Delete a file |
| `glob` | Find paths by glob (respects `.gitignore`) |
| `grep` | Search file contents (respects `.gitignore`) |
| `ls` | List one directory, not recursive. Path must be absolute |
| `apply_patch` | Apply a patch when the model and transport are eligible; replaces the legacy file tools on that path |

Edits and deletes wait for [approval](../agent/approvals.mdx) on the default level.

## web_fetch

`web_fetch` retrieves an `http` or `https` URL and returns Markdown. It is a host tool, not a provider built-in search. Use it when the agent needs a page that is not in the workspace.
