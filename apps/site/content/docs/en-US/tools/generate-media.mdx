---
title: Generate media
description: generate_image and generate_video use the image and video model slots.
---

Spirit can generate an image or a short video when you have assigned those default models in **Settings → Models**.

| Tool | Arguments |
| --- | --- |
| `generate_image` | `prompt` (required), optional `size` as `WIDTHxHEIGHT` |
| `generate_video` | `prompt` (required), optional `duration` (4–15 seconds), `aspect_ratio`, `resolution` |

Ask mode cannot call these tools. The composer can also take a direct generate-image / generate-video shortcut when those slots are set.

Results are stored as generated assets. The agent can read them later with `read_file` on a `spirit://generated/image/…` or `spirit://generated/video/…` URI.

If the tools are missing, the active provider catalog did not mark image or video generation, or the slots are empty. Connect a provider that exposes those capabilities, then assign the slots. See [Providers](../providers/index.mdx).
