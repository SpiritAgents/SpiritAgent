---
title: LSP
description: Enable language servers under Settings → Agents.
---

Spirit can talk to language servers for diagnostics and related editor help. Turn them on in **Settings → Agents**, then install a provider if it is missing.

| Id | Languages | How it is installed |
| --- | --- | --- |
| `typescript-language-server` | TypeScript, JavaScript | npm (`typescript-language-server`) |
| `pyright` | Python | npm (`pyright`) |
| `gopls` | Go | Go toolchain |
| `rust-analyzer` | Rust | rustup |
| `clangd` | C, C++ | Platform package (for example Homebrew or winget) |
| `jdtls` | Java | Manual |
| `omnisharp` | C# | .NET |

clangd and jdtls are not bundled. Install them yourself, then come back to Settings → Agents.

LSP is not a substitute for tests. The agent still needs you (or CI) to run the project test command.
