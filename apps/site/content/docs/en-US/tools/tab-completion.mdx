Tab Tab Tab is **editor inline completion**. It is not the agent conversation, and it is not the Tab key that cycles [Agent / Plan / Ask / Debug](../agent/modes.mdx).

## Turn it on

1. Open **Settings → Tab**.
2. Enable code completion (`codeCompletionEnabled`).
3. Assign a **Lightweight Chat Model** in **Settings → Models**. That slot also serves other lightweight background tasks.

Suggestions appear as ghost text in the Monaco editor. Accept with Tab.

## What it is not

- It does not edit files through `edit_file` or wait for approval.
- It does not run shell, Git chips, or Browser.
- Turning the agent to Ask or Plan does not change Tab completion.

If completion is empty, check that a lightweight chat model is connected and that the setting is on.
