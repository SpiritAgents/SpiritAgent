---
title: Connect SpaceXAI
description: Connect SpaceXAI (provider id `xai`) with a Chat Completions key.
---

Create an API key in the [SpaceXAI console](https://console.x.ai/team/default/api-keys).

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

Fixed **Chat Completions API** (`openai-compatible`). Default base: `https://api.x.ai/v1`.

## Capabilities

Chat after import. Reasoning, image, and video follow the imported catalog — assign slots when they appear.
