title: Connect StepFun
description: Connect StepFun, optionally on the Step Plan endpoint.
---

Create an API key on the [StepFun platform](https://platform.stepfun.com). Step Plan notes: [Step Plan](https://platform.stepfun.com/docs/zh/step-plan/integrations/reasoning-api).

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

Fixed **Chat Completions API**. Default base: `https://api.stepfun.com/v1`.

## Plan endpoint

**Step Plan** switches to `https://api.stepfun.com/step_plan/v1`.

## Capabilities

Chat after import. Reasoning follows the model.
