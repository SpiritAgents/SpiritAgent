title: Connect Groq
description: Connect Groq over Chat Completions.
---

Create an API key in the [Groq console](https://console.groq.com).

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

Fixed **Chat Completions API**. Default base: `https://api.groq.com/openai/v1`.

## Capabilities

Chat after import. Reasoning follows the model when Groq exposes it.
