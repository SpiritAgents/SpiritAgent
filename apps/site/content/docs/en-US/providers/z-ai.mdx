title: Connect Z.ai
description: Connect Z.ai, optionally on the GLM Coding Plan endpoint.
---

Create an API key in the [Z.ai console](https://z.ai/manage-apikey/apikey-list). Coding Plan notes: [GLM Coding Plan](https://docs.z.ai/devpack/quick-start).

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

Fixed **Chat Completions API**. Default base: `https://api.z.ai/api/paas/v4`.

## Plan endpoint

Turn on **GLM Coding Plan** in the wizard to use `https://api.z.ai/api/coding/paas/v4` instead of the default PaaS base.

## Capabilities

Chat after import. Reasoning follows the model.
