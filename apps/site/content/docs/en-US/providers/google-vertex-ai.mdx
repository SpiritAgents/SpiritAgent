---
title: Connect Google Vertex AI
description: Connect Vertex AI with a GCP project, location, and an auth mode.
---

Use a GCP project that has Vertex AI enabled. Auth is ADC, a service account, or an Express API key — not a generic OpenAI key.

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

Fixed **Chat Completions API**. Responses or Messages requests fall back to Chat Completions. Base becomes `https://{location}-aiplatform.googleapis.com/v1/projects/{project}/locations/{location}`.

## Cloud fields

- **GCP Project ID** and **Location** (required), for example `us-central1`
- **Authentication**
  - **ADC** — Application Default Credentials on this machine (`GOOGLE_APPLICATION_CREDENTIALS`)
  - **Service Account** — client email + private key; used to fetch the model list
  - **Express API Key** — cannot fetch the catalog; add a model id by hand

## Capabilities

Chat after a model is selected. For AI Studio keys without a GCP project, use [Google](./google.mdx).

## Known pitfalls

Express mode cannot import the model list. Service account mode needs both email and private key to list models.
