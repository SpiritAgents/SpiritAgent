---
title: Connect BytePlus
description: Connect BytePlus Ark and pick Chat Completions or Responses.
---

Create an API key in the [BytePlus Ark console](https://console.byteplus.com/ark/apiKey).

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

Picker: **Chat Completions** or **Responses API**. Default base: `https://ark.ap-southeast.bytepluses.com/api/v3`.

## Capabilities

Chat after import. Other capabilities follow the catalog.
