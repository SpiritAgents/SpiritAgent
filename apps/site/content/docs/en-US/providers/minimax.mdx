---
title: Connect MiniMax
description: Connect MiniMax over the Messages API and pick China or International.
---

Create an API key in the MiniMax console for the site you will use: [China](https://platform.minimaxi.com/console/) or [International](https://platform.minimax.io/console/).

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

Fixed **Messages API** (`anthropic`). International Messages base: `https://api.minimax.io/anthropic/v1`.

## Site

- **International** (default) — `https://api.minimax.io/v1` (Chat-shaped) / `https://api.minimax.io/anthropic/v1` (Messages)
- **China** — `https://api.minimaxi.com/v1`

## Capabilities

Chat after import. The upstream `/models` list has no multimodal flags; only M3 is treated as supporting image / video input.

## Known pitfalls

Through Vercel AI Gateway on Open Responses, MiniMax M3 does not return a displayable thinking stream.
