---
title: Connect Kimi Code
description: Connect the Kimi Code coding endpoint, separate from Moonshot AI.
---

Create a Kimi Code API key in the [Kimi Code console](https://www.kimi.com/code/console).

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

Fixed **Chat Completions API**. Default base: `https://api.kimi.com/coding/v1`. A Messages base exists at `https://api.kimi.com/coding` but the wizard does not offer a picker.

## Capabilities

Chat after import. Hosted search, when available, is specific to this provider — not moonshot-ai.
