---
title: Connect Hugging Face
description: Connect the Hugging Face router with an access token over Open Responses.
---

Create a token in [Hugging Face settings](https://huggingface.co/settings/tokens).

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

Fixed **Open Responses API**. Default base: `https://router.huggingface.co/v1`.

## Capabilities

Chat after import. Other capabilities follow the router catalog.
