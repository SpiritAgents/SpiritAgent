---
title: Connect Moonshot AI
description: Connect Moonshot AI and pick the China or International site.
---

Create an API key in the Moonshot console for the site you will use.

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

Fixed **Chat Completions API**. No transport picker.

## Site

- **International** (default) — `https://api.moonshot.ai/v1`
- **China** — `https://api.moonshot.cn/v1`

This is the Moonshot Open Platform provider, not [Kimi Code](./kimi-code.mdx).

## Capabilities

Chat after import. Built-in search on moonshot-ai does not use the Kimi Code hosted search path.

## Known pitfalls

A Kimi Code key and a Moonshot Open Platform key are different connections.
