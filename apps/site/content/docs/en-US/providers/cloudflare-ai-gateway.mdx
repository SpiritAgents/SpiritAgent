---
title: Connect Cloudflare AI Gateway
description: Connect with a Cloudflare account id, optional gateway id, and an API token.
---

Create an API token in the [Cloudflare dashboard](https://developers.cloudflare.com/ai-gateway/). You also need the account ID.

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

Picker: **Chat Completions**, **Open Responses**, or **Messages**. Base is built from the account: `https://api.cloudflare.com/client/v4/accounts/{accountId}/ai/v1`.

## Cloud fields

- **Account ID** (required) — 32-character hex
- **Gateway ID** (optional)

Without an account ID the wizard cannot build the API base.

## Capabilities

Chat and other capabilities follow the models the gateway exposes.
