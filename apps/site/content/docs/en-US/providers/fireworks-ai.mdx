---
title: Connect Fireworks AI
description: Connect Fireworks Inference with an optional transport pick.
---

Create an API key in the Fireworks console.

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

Picker: **Chat Completions**, **Messages**, or **Open Responses**. Chat / Responses base: `https://api.fireworks.ai/inference/v1`. Messages base: `https://api.fireworks.ai/inference`.

## Capabilities

Chat after import. Other capabilities follow the Fireworks catalog.
