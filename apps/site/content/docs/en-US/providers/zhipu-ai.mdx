title: Connect Zhipu AI
description: Connect Zhipu AI (BigModel), optionally on the GLM Coding Plan endpoint.
---

Create an API key on [open.bigmodel.cn](https://open.bigmodel.cn). Coding Plan notes: [GLM Coding Plan](https://docs.bigmodel.cn/cn/coding-plan/quick-start).

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

Fixed **Chat Completions API**. Default base: `https://open.bigmodel.cn/api/paas/v4`.

## Plan endpoint

Turn on **GLM Coding Plan** to use `https://open.bigmodel.cn/api/coding/paas/v4`.

## Capabilities

Chat after import. Reasoning follows the model.
