title: Connect SiliconFlow
description: Connect SiliconFlow, pick a site, and choose Chat Completions or Messages.
---

Create an API key in the SiliconFlow console for the site you will use.

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

Picker: **Chat Completions** or **Messages**.

## Site

- **International** (default) — `https://api.siliconflow.com/v1`
- **China** — `https://api.siliconflow.cn/v1`

## Capabilities

Chat after import. Other capabilities follow the catalog.
