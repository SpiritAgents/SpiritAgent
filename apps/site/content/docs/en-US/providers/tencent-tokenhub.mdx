---
title: Connect Tencent TokenHub
description: Connect TokenHub and pick Guangzhou or Singapore. Transport is Chat Completions only.
---

Create an API key in the Tencent TokenHub console.

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

Fixed **Chat Completions API**. The wizard does not offer Responses or Messages.

## Site

- **Guangzhou** (default) — `https://tokenhub.tencentmaas.com/v1`
- **Singapore** — `https://tokenhub-intl.tencentmaas.com/v1`

## Capabilities

Chat after import. Do not rely on Chat-injected web search.

## Known pitfalls

TokenHub documents Chat `web_search_options` and Responses `web_search`, but Chat injection does not work in practice, and Responses is only on a few models. Spirit therefore keeps Chat Completions only.
