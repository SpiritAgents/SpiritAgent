---
title: Connect DeepSeek
description: Create a DeepSeek key and connect. The wizard does not show a transport picker.
---

Create an API key on the [DeepSeek platform](https://platform.deepseek.com/api-keys).

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

No picker. The connect default is **Open Responses** (`open-responses`). Compatible bases also exist at `https://api.deepseek.com/v1` (Chat) and `https://api.deepseek.com/anthropic` (Messages).

## Capabilities

Chat after import. Reasoning follows the model.
