---
title: Connect Anthropic
description: Create a key in the Anthropic console and connect over the Messages API.
---

Create an API key in the [Anthropic console](https://console.anthropic.com/settings/keys).

## Connect

<Tabs items={["Desktop", "CLI"]}>
  <Tab value="Desktop">

1. Open **Settings → Models**.
2. Choose this provider and finish the connect wizard.
3. Spirit writes the key to the system keyring (`SpiritAgent`), then imports models.

  </Tab>
  <Tab value="CLI">

In the TUI run `/model add`, or from the shell:

```bash
spirit model add
```

  </Tab>
</Tabs>

## Transport

Fixed **Messages API** (`anthropic`). Default base: `https://api.anthropic.com/v1`.

## Capabilities

Chat after import. Reasoning follows the model. No Spirit-side image or video generation slot unless a later catalog entry marks it.
