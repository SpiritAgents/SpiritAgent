# Privacy Policy

Last updated: 2026-07-25

Spirit is an open-source application that runs locally on your device. This policy describes how the software handles information.

## Summary

- We do **not** operate analytics, advertising, or telemetry services that collect personal data from the app.
- Configuration, API keys, conversation history, and workspace-related state are stored **on your device** by default.
- When you connect to third-party services you configure (such as model providers or MCP servers), content you send through those integrations is transmitted to those services under **their** terms and privacy policies.

## Data stored on your device

Depending on how you use Spirit, the app may store locally:

- Application and workspace settings
- Model provider configuration and API credentials you supply
- Conversation / session history
- Other workspace-bound state needed for the product to function

You control this data through your device, OS backups, and the app’s own delete/clear flows.

## Third-party services

Spirit does not provide the model APIs themselves. If you configure and use a model provider, MCP server, or similar external service, prompts, conversation content, tool-related context, and other data required for that request may be sent to that provider.

We do not control how third parties process that data. Review each provider’s privacy policy before use.

## No developer telemetry

The current product does not include developer-operated usage telemetry or analytics reporting.

## Changes

We may update this policy as the project evolves. The latest version will be in this file in the repository.

## Contact

For privacy questions about this project, open an issue in the Spirit GitHub repository.
